# TYPEFIRE

A minimalist typing speed test.

**[Play now →](https://typefire-game.github.io/)**

---

Choose 15, 30, or 60 seconds and type as fast as you can. Passages are drawn from science, mathematics, and philosophy texts sourced from Wikipedia. Submit your score to the global leaderboard and see how you rank.

## Features

- Three timed modes: 15s / 30s / 60s
- Real-time WPM, accuracy, and error tracking
- Global leaderboard (top 100 scores per mode)
- Installable as a PWA (works offline after first load)
- No account required
